# Resources and Tools

## Game development and research

| Resource | Use | Public link |
| --- | --- | --- |
| Claude Code | Assisted generation of game code and code-rendered SVG/CSS illustrations. | https://www.anthropic.com/claude-code |
| OpenAI Codex | Assisted gameplay integration, code changes, testing and documentation. | https://openai.com/codex/ |
| Google Gemini | Assisted discovery and organization of research references. | https://gemini.google.com/ |
| Noto Sans SC | Bundled Chinese font, distributed under the SIL Open Font License 1.1. | https://github.com/notofonts/noto-cjk |
| Node.js | Local development and automated checks. | https://nodejs.org/ |
| Git | Version control. | https://git-scm.com/ |
| GitHub | Public code hosting. | https://github.com/ |
| GitHub CLI | Repository publication tooling. | https://cli.github.com/ |

AI assistance is also recorded in project-metadata.json. AI-assisted text and research summaries are not independently verified NASA data. Artwork is rendered from game code; there is no runtime AI service or external stock-image package.

## Presentation production

Canva (https://www.canva.com/) and CapCut (https://www.capcut.com/) were used for the team's presentation/video work. Those media files are supplied separately and are not game dependencies.

## Licenses and NASA attribution

The font license is preserved in game/fonts/OFL.txt. NASA references are listed in NASA_DATA.md and do not imply NASA endorsement. No NASA logo is required to play the game.
