# Current Integrated Game

This directory contains OxyNest's current modified settlement game, based on teammate B's November 13 Kids handoff. It supersedes the original game snapshot at this path; the original remains preserved in Git history at e55dbbcdbb272dfb590db81d5eaf1924b44d2364.

Open index.html locally, or follow the repository root README for build and development commands. Choose Build my base for autonomous management or Guided missions for the optional campaign. The two modes save separately. There is no background music.

See ../docs/SETTLEMENT_MODE_2026-11-13.md for current rules, ../docs/KIDS_HOW_TO_PLAY.md for controls and ../CREDITS.md for attribution. Existing game/docs/FACTS.md describes supplied learning references; those references still need scientific-content review. Game costs, yields and timers are simplified assumptions.
